Philosophy

Software should be
simple to own.

The tools came first. Internal solutions for a real manufacturing company, built in spare time out of curiosity about AI-assisted development with Claude Code. They ended up on GitHub anyway. jcapps is the public version of that.

01

No infrastructure overhead

Every JCApps tool runs on plain PHP with flat-file storage. No database setup, no Redis, no message queues. If your hosting supports PHP, you're ready.

02

Your data stays yours

Files and data are stored on your own server. We have zero access, zero telemetry, zero analytics. What happens on your server stays on your server.

03

Built to last

No framework dependencies that break with every update. Plain PHP, vanilla JS, and CSS that works in five years the same as it does today.

Origin

Built with
Claude Code.

jcapps started as internal tooling for a real manufacturing company — written collaboratively with Claude Code, in spare time, out of curiosity about what AI-assisted development can actually produce.

Not a demo. Not a template. Real software, handling real data, running in production since early 2026.

The tools worked well enough to share.
